# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, accept constructive criticism, focus on what is best for the
community, and do not harass anyone, in any form.

Report unacceptable behaviour privately to the maintainers through GitHub (a private security advisory or a
direct message to a maintainer). Reports are handled confidentially. Maintainers may remove comments, commits
or contributions, and ban contributors, that break this code of conduct.
